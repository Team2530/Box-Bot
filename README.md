# Box-Bot

This is intended for use for vision prototyping until the competition robot is ready.

## In use
- 2 LL3's for apriltags
- Pi5 PhotonVision

# Accessing the LL's
- The Limelights are named A and B (labeled with tape),  so connecting to the robot and accesing limelight-[a|b].local:5801 will provide the config dashboard.
